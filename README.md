# q6z4ixckpage

A clean, minimalist personal landing and link-in-bio page showcasing music and social profiles with dark and light visual themes.

---

## Features

- **Theme Variants:** Visual backgrounds supporting light (`bg-light.jpg`) and dark (`bg-dark.jpg`) aesthetics.
- **Social & Music Hub:** Direct icon links to platforms:
  - Apple Music
  - Spotify
  - YouTube
  - Instagram
- **Zero Dependencies:** Built entirely with standard HTML and vanilla styling—fast loading, responsive, and lightweight.
